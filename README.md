## 📄 Research Publication

> **Prompt-Driven Tool-Calling for Lightweight Open Source LLMs**

**Conference:** 3rd International Conference on Artificial Intelligence and Sustainable Computing for Smart Cities (AIS2C2 2025)  
**Author:** Pawan Yadav · **Pages:** 493–497 · **ISBN:** 978-93-94086-43-2

**What problem does this research address?**

As Large Language Models become more capable, one major challenge remains: *how can smaller, open-source LLMs perform complex tasks without requiring massive computational resources?*

This research explores a **prompt-driven tool-calling framework** that enables lightweight open-source LLMs to:

✅ Use external tools effectively  
✅ Perform multi-step reasoning workflows  
✅ Reduce dependence on large proprietary models  
✅ Move us closer to practical, cost-efficient AI agents in resource-constrained environments
